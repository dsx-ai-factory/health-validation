InfiniBand covers InfiniBand network health: port state, error rates, and link integrity.

## RDMA Link Flap (Fatal)

`rdma_linkflap_fatal`

Detects mlx5 RDMA interface link outages that lasted at least min_outage_seconds, parsed from the system journal. Fails CRITICAL once the count of such outages reaches fatal_flap_threshold.
