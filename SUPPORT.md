# Support

## Support Level

**Maintained**

| Level | Meaning |
|-------|---------|
| Experimental | Active development; APIs and behavior may change without notice. |
| Maintained | Best-effort support; critical bugs fixed; breaking changes announced in advance. |
| Stable | Production-ready; semantic versioning respected; deprecations communicated with a migration window. |

## How to Get Help

| Need | Where to go |
|------|-------------|
| Bug report | [GitHub Issues → Bug](../../issues/new?template=bug.yml) |
| Feature request | [GitHub Issues → Feature](../../issues/new?template=feature.yml) |
| General question | [GitHub Discussions](../../discussions) |
| Security vulnerability | See [SECURITY.md](SECURITY.md) — **do not file a public issue** |

## Response Expectations

This is an open-source project maintained by a team at NVIDIA. We aim to
acknowledge new issues within **5 business days** and provide a substantive
response within **10 business days**, but this is not a formal SLA.

Critical security vulnerabilities are prioritized and handled on an expedited
timeline per [SECURITY.md](SECURITY.md).

## Enterprise / Commercial Support

For enterprise support options, contact your NVIDIA account team or visit
[nvidia.com/support](https://www.nvidia.com/support).
